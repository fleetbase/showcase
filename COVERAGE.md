## Google Maps variants

The console switches the *live operations map* (orders index, order details, the drawer's
position listing) to Google Maps when Fleet-Ops → Settings → Map has `mapProvider = google`
and the API exposes a key (`GOOGLE_MAPS_API_KEY` on the API container; the console fetches it
via `fleet-ops/settings/map`). Everything else that draws a map — geofence and service-area
editors, place pickers, the tracking page — is Leaflet-only in the engine, so a "Google
variant" is meaningful for the live-map screens only: today `live-orders-panel` and
`multi-waypoint-order`, later the position playbacks.

Constraints that shape the implementation (PR *feature/google-maps-variant*):
- the key is a secret (`GOOGLE_MAPS_API_KEY`), restricted by HTTP referrer to
  `http://proxy/*` and `http://localhost/*`;
- Google's terms forbid caching tiles, so these captures hit the network live and are not
  byte-stable between runs — the compare step does not auto-stage `-google` files;
- Google's attribution and logo must remain visible in any published image.
