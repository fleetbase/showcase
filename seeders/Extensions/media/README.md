# Extension media

Served to the browser at `/showcase-registry/` by the proxy (`docker/caddy/Caddyfile`), for the
Extensions screens of Fleetbase v0.9.0 and later. `docker/registry/server.mjs` names these
files in the catalogue it serves from `../catalog.json`.

## icons/

One per extension, named by its slug. Each is a Font Awesome 6 Free solid glyph (CC BY 4.0, the
icon set the console ships) in white on a diagonal gradient: the `glyph` and `colors` of the
extension's entry in `catalog.json`. They are generated by `../build-icons.mjs`, not drawn, so
the set stays consistent. None is a third party's logo.

To use a real logo, replace `icons/<slug>.svg` by hand. An extension with no icon file is shown
with the console's own monogram (its first letter on a colour).

## screenshots/

The images on an extension's page, listed under `screenshots` in its catalogue entry. They are
Fleetbase's own published console screenshots (from fleetbase.io), resized to 1600 px wide.
